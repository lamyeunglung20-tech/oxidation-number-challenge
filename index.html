氧化數筆記

1元素的氧化數為 0

未與其他元素化合的元素，不論是單原子或分子，氧化數都是 0。

Na：0H₂：H = 0O₂ / O₃：O = 0Cl₂：Cl = 0

2單原子離子的氧化數等於其電荷

Cu²⁺：+2Cl⁻：−1Al³⁺：+3

3離子化合物：拆開陽離子和陰離子

化合物陽離子陰離子
NaClNa = +1Cl = −1
K₂OK = +1O = −2
MgBr₂Mg = +2Br = −1
Al₂O₃Al = +3O = −2

4化合物中的常用規則

元素通常氧化數例子／例外
第 I 族+1KOH、NaCl、Li₂O
第 II 族+2MgO、MgSO₄、Ca(NO₃)₂
氫+1金屬氫化物 NaH 中 H = −1
氧−2過氧化物 H₂O₂ 中 O = −1

5氧化數總和規則

中性化合物：所有原子的氧化數之和 = 0。

H₂O：2(+1) + O = 0 → O = −2

多原子離子：所有原子的氧化數之和 = 離子電荷。

PO₄³⁻：P + 4(−2) = −3 → P = +5

物種算式答案
